# UI/UX Design System

Approved direction: light-first professional Gym Owner workspace and distinct light-first Super Admin console. White/light-neutral surfaces, subtle borders, premium typography, restrained shadows and electric blue/violet accents. Support dark, light and system themes.

Use shadcn/ui and licensed Shadcn Studio components where available, Lucide React icons, accessible forms/dialogs/dropdowns, data tables, status badges, charts, toasts and responsive navigation.

Avoid crowded glowing cards, excessive gradients and fake production metrics. Financial figures must reconcile. Every button must work or be clearly disabled. Support keyboard navigation, focus states, contrast, accessible labels and loading/empty/error states. Responsive web views are not the Phase 1 native app. Concepts 04 and 05 are references, not pixel-perfect final designs.
