# Build Plan and Milestones

M0 — Inspect repository, establish folder structure, environment validation, lint/type-check/test baseline and CI.
M1 — Clerk verification, internal roles, tenant resolver, authorization middleware, audit log and cross-tenant tests.
M2 — GymSphere subscription plans, UTR submission, proof upload, duplicate detection, Super Admin review and idempotent approval/rejection.
M3 — Resumable onboarding, gym profile, branches, membership plans, fee settings, attendance settings and checklist.
M4 — Members and membership lifecycle.
M5 — Charges, full/partial payments, balances, receipts and adjustments/refunds.
M6 — Attendance, duplicate check-in protection, history and authorized overrides.
M7 — In-app notifications, web push, email reminders, scheduler, retries and delivery logs.
M8 — Dashboard, reports, marketing content and SEO.
M9 — Security hardening, accessibility, backups, E2E and staging deployment.
Phase 2 — Native member app only after Phase 1 is stable.

Each milestone must be verified before moving on. Do not claim tests passed unless executed.
