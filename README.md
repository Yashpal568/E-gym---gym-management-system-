# GymSphere

GymSphere is a multi-tenant gym management SaaS. Phase 1 is a web-only product with a Gym Owner app, separate Super Admin console, marketing website, Node.js backend, Clerk authentication, manual UTR subscription approval, guided onboarding, member/fee/attendance management, and web/email notifications.

## Documentation

See `docs/` for the separated PRD, architecture, database, API, security, UI/UX, milestones, testing, and operations documents. Start at `docs/00_START_HERE/PROJECT_OVERVIEW.md`.

## Current state

This repository is being initialized from the approved GymSphere Phase 1 documentation baseline. Native member mobile app is Phase 2.
